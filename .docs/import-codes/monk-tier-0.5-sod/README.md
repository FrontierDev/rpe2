# Monk Tier 0.5 — Cloudwalker Raiment — RPE Import Codes

This folder contains three invented level-60 Monk Dungeon Set 2 / Tier 0.5 variants under the shared **Cloudwalker Raiment** set family:

- **Cloudwalker Raiment — Windwalker DPS** — 8 pieces.
- **Cloudwalker Raiment — Brewmaster Tank** — 8 pieces.
- **Cloudwalker Raiment — Mistweaver Healer** — 8 pieces.

## RPE normalization

- Dataset: `monkdata`
- Class: `monkdata:monk0001`
- Required level: **60**
- Item level: **60**
- Armor weight: **Leather**
- Binding: **Bind on Pickup**
- Shared item-set key: `t05_monk_cloudwalker`
- Chest, feet, hands and head are **Epic**.
- Legs, shoulders, waist and wrists are **Rare**.
- No sockets are added, matching the existing RPE Tier 0.5 convention.
- Every piece supports generic modifier key `mod`, capped at **1**.
- **Windwalker** copies the existing Darkmantle DPS stat budget.
- **Brewmaster** copies the existing Darkmantle tank stat budget.
- **Mistweaver** copies the existing Feralheart Restoration stat budget.
- No set-bonus mechanics are embedded in item descriptions.
- `Cloudwalker Raiment` is an invented Monk Tier 0.5 set name; it is not presented as a canonical Blizzard set.
